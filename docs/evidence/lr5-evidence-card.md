# Evidence card ЛР5 — шаблон

Каждый участник копирует файл в `docs/evidence/lr5-<github-login>.md` и заполняет его сам.
Карточка входит в тот же PR, что и работа участника. Поля — из раздела 16 задания ЛР5.

| Поле | Значение |
|---|---|
| Студент | ФИО, группа, команда №4, GitHub-логин |
| Роль | Роль в ЛР5 и отличие от ЛР4 |
| Задача | Ссылка на issue с критерием приемки |
| Личный артефакт | Test node ID, fixture, PR, review или отчет |
| Контролируемый риск | Ошибка, которую обнаруживает тест |
| Defect injection | Внесенный дефект, заранее названный и фактически упавший тест |
| Диагностика | Первый полезный фрагмент traceback и причина |
| Воспроизведение | Точная команда запуска одного теста и всего набора |
| Использование ИИ | Инструмент и самостоятельно проверенные утверждения либо отсутствие использования |
