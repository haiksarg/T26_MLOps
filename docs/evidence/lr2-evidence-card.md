# Evidence card ЛР2 — шаблон

Каждый участник копирует этот файл в `docs/evidence/lr2-<github-login>.md` и заполняет его
самостоятельно. Одинаковый текст у нескольких участников не засчитывается (ЛР2, п. 15.3).
Ссылки должны открываться и соответствовать истории GitHub.

| Элемент | Значение |
|---|---|
| Идентификация | ФИО, группа, команда №4, GitHub-логин и роль в ЛР2 |
| Собственный вклад | 2–4 изменения со ссылками на issue, PR, commit и строки diff |
| Проверка коллеги | Ссылка на review, найденная проблема или проверенный критерий |
| Воспроизведение | Команда запуска валидатора, SHA-256 из отчета и результат успешной проверки |
| Отрицательный сценарий | Самостоятельно внесенное нарушение и название сработавшей проверки |
| Обоснование | Правило контракта, риск утечки и ограничение набора |
