# Evidence card ЛР3 — шаблон

Каждый участник копирует этот файл в `docs/evidence/lr3-<github-login>.md` и заполняет его
самостоятельно. Карточка входит в тот же PR, что и работа участника.
Одинаковый текст у нескольких участников не засчитывается. Ссылки должны открываться.

| Элемент | Значение |
|---|---|
| Идентификация | ФИО, группа, команда №4, GitHub-логин и зона результата в ЛР3 |
| Собственный вклад | 2–4 изменения со ссылками на issue, PR, commit и строки diff |
| Проверка коллеги | Ссылка на review, найденная проблема или проверенный критерий |
| Воспроизведение | `dvc repro` с нуля: команды, ответ `dvc status`, MD5 своего результата из `dvc.lock` |
| Изменение параметров | Какой параметр изменен, какие стадии перезапустились, вывод `dvc params diff` |
| Обоснование | Решение в своей стадии, риск (утечка или невоспроизводимость) и как он обнаруживается |
